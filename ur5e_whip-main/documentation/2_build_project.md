# Build the Project

```bash
cd ~/ros2_ws && colcon build --mixin release
```

Your file structure should look like this:

```
home/
└── ros2_ws/ (build here)
    ├── build/
    ├── install/
    ├── log/
    ├── src/
    │   └── ur5e_whip
    │   └── realsense-ros
    │   └── camera-calibration-with-large-chessboards
```
