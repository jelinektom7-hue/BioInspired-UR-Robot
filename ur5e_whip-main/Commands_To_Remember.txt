Connect and test on robot arm:

1. Physically connect

Connect the Ethernet cable between laptop and UR5e controller.

2. Set laptop Ethernet IPs

sudo ip addr flush dev eno1
sudo ip addr add 192.168.0.101/24 dev eno1
sudo ip addr add 192.168.0.10/24 dev eno1
sudo ip link set eno1 up

3. Test network connection

Run:

ping 192.168.0.100

4. Source ROS 2 and workspace

In a new terminal:

deactivate 2>/dev/null
export PYTHONNOUSERSITE=1
source /opt/ros/humble/setup.bash
source ~/ros2_ws/install/setup.bash

5. Launch the UR ROS 2 driver

Run:

ros2 launch ur_robot_driver ur_control.launch.py \
  ur_type:=ur5e \
  robot_ip:=192.168.0.100 \
  reverse_ip:=192.168.0.10 \
  launch_rviz:=false

6. Start External Control on the pendant

On the UR pendant:

Open the program, probably called:
Control by tomas
Make sure it uses External Control.
Make sure the remote host is:
192.168.0.10
Make sure the port is:
50002
Press Play.

Set the speed slider low, around 5–10%.

7. Check that ROS sees the robot properly

Open another terminal and source ROS again:

deactivate 2>/dev/null
export PYTHONNOUSERSITE=1
source /opt/ros/humble/setup.bash
source ~/ros2_ws/install/setup.bash

Check speed scaling:

ros2 topic echo /speed_scaling_state_broadcaster/speed_scaling --once

Check the trajectory controller:

ros2 control list_controllers | grep trajectory

Expected:

scaled_joint_trajectory_controller ur_controllers/ScaledJointTrajectoryController active

Check joint states:

ros2 topic echo /joint_states --once
