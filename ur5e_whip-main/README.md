# ur5e_whip

Run the following commands to set up the repository correctly:

```bash
$ mkdir -p ~/ros2_ws/src
```
```bash
$ cd ~/ros2_ws/src
```
```bash
$ git clone git@github.com:peterfryd/ur5e_whip.git
```

## Step 1: Dependencies
Follow instructions in [dependencies](https://github.com/peterfryd/ur5e_whip/tree/main/documentation/1_dependencies.md).

## Step 2: Build the Project

Follow instructions in [build project](https://github.com/peterfryd/ur5e_whip/tree/main/documentation/2_build_project.md).

## Step 3: Run Nodes

Follow instructions in [run nodes](https://github.com/peterfryd/ur5e_whip/tree/main/documentation/3_run_nodes.md).
